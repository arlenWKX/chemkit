## 1. 怎么跑（最常用的四条）

```bash
python tools/dev.py suite            # 全量套件（~2 min；1020/1176 即当前预期，非全绿）
python tools/dev.py perf             # 确定性与性能指标（对比受控基线）
```

**提交门槛（硬性）**：两套 pKw 约定**都**要 `1299/1299`
（当前因半成品状态**未达标**，见 §2）。另有 `eqcheck`（方程守恒 0 违规）、
`hygiene --fix`（编码/行尾）。

**分层测试协议**见 [`tools.md`](tools.md)：T0 不跑 / T1 定向 / T2 全量 /
T3 双约定+perf+审计。**默认 T1**；回退到已知状态**不要重测**。

**本轮新增的诊断工具**（未入库，根目录 `.tmp_` 前缀，可复用）：

  （第 198→199 轮即此范例：pinned 首版变差，查明病根后修好而非回退）。

  但本轮核对的 E55/N22/T51/16 标准都是化学事实，不许动。
* 一切数据改动走 `dev.py patch` 或 `tools/jsondb.py`（**按键路径**，不用文本锚串）。
* 记忆值**不得**当已核数据：查不到出处就**不入库**，或写
  `calibrated: provenance 未核实` 并单列待复核。
* 每轮：**建/更新 todo**、一次运行**全量结构化留档**（`logs/`）、
  轮末入档 `log.md` + 更新 `lessons.md` + 提交 + 汇报指标。
