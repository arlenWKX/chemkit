## 3. 下一步（**优先级最高，已定位**）

### 3.1 修 `pinned` 接管（第 198 轮，进行中）
第 197 轮查明病灶 **E55 明矾+适量NaOH**：`h_c = o_c = 2.49e-4`（退化区，
触发条件本就满足），但被"**排除固相储库**"那条闸挡住——账本里有
**Al(OH)₃ 固相 0.9738 mol**，而 `estimate_state` 的精确解要求"无固相"。

**已做的尝试**：对在场的 OH⁻ 型固相构造 `pinned` 项
（`(charge_of(cat), _pksp(e,T_K), x, y)`）、从账本删掉该阳离子条目，
再调 `charge_pH(..., pinned=...)`。

**待查**：为何反而更差。检查方向：
1. `pinned` 的 `z` 是否应取阳离子电荷（文档 `(z, pKsp, x, y)`）；
2. 删阳离子条目会改变 `fam` 族平衡与 `build_families` 的成员集，
   是否需要在删之前先算族；
3. 是否对所有在场固相都钉住（含 CaCO₃ 等非 OH⁻ 型不适用）；
4. 触发面是否过宽（把本来正确的用例也拉进精确解）。

**判据**：E55 的 `resid_src`（`Al³⁺ → Al(OH)₃ + 3H⁺`，S=18.83）应显著下降、
Al³⁺/Cr³⁺ 那 12 例（E55/N34/U01/16/NR22/E25/NR114/I13/D41/Amp15…）改善，
且**其余族不得翻红**。

### 3.2 逐族重裁标准（下一阶段主体工作）
时间有限、已明确要做的：按体系族核对 196 例 `|S|>0.1` 里那 133 例"跨界"
的化学合理性，**判据用文献锚而非引擎输出**。已定位的两族：
* **Al³⁺/Cr³⁺ 碱量不足族**（18.8 量级）——**电荷平衡硬约束 + X-45 帧选错**，
  见 §3.1；
* **卤素族**（`Cl₂+NaBr` 三例同为 9.434）——**结案：痕量反应物计量上限**
  （`ext_max` 仅 0.0017），非缺陷。

## 8. 纪律（不可违背，详见 lessons.md / discipline.md）

* **一切以化学事实为准**；不为迎合测试标准而舍弃更本质的做法。
* **数据与引擎缺陷分开记账**，不许互相掩盖（`db_matrix` 出清单）。
* **测试库标准可能有错**：先问"这是化学事实，还是某次引擎输出的快照"。
* 一切数据改动走 `dev.py patch` 或 `tools/jsondb.py`（**按键路径**，不用文本锚串）。
* 记忆值**不得**当已核数据：查不到出处就**不入库**，或写
  `calibrated: provenance 未核实` 并单列待复核。
* 每轮：**建/更新 todo**、一次运行**全量结构化留档**（`logs/`）、
  轮末入档 `log.md` + 更新 `lessons.md` + 提交 + 汇报指标。
