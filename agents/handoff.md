## 1. 五分钟上手

纯标准库（Python >=3.12）水溶液反应引擎：输入"往水里加了什么"，输出最终物种
分布、pH、净反应方程式、反应程度。数据与引擎严格分离。

```bash
python tools/dev.py suite            # 全量回归（1378 例）
python tools/dev.py suite J05 NR23   # 按名字前缀跑子集
python tools/dev.py case  EU01       # 单例深探
python tools/dev.py eqcheck          # 用例期望方程式精确守恒（须 0 违规）
python tools/dev.py patch spec.py    # 数据表声明式补丁（原子 + 计数断言）
python tools/quick.py NR23 NR108     # 子集快跑
python tools/hess_audit.py --T 273.15 --T 363.15 --with-templates
```

目录：`chemkit/`（引擎）· `chemkit/data/*.json`（唯一事实源）· `tools/`（诊断
与批处理，`dev.py` 是总入口）· `agents/`（工作文档）· `docs/`（用户文档）。

## 3. 改代码前必须知道的约定

### 3.1 三层视图（判"引擎错还是断言错"的第一动作）

| 层 | 取法 | 性质 |
|---|---|---|
| 账本 | `judge(..., _probe=pr)["ledger"]` | 化学真值所在 |
| 净差 | 引擎渲染的 `initial -> final` 之差 | 引擎自己的解释 |
| 呈现 | `Reaction.consumption / production / final` | `testsuit` 的 `has*` 只读这层 |

工具：`tools/specdist.py <前缀>` 三层并列。

### 3.2 动力学"慢"的表征（易错，第 301 轮踩过）

同一个"慢"有多种容器，**适用时机不同**：
* `slow`（配对级，两方向恒慢）⟹ 方向未定前可整条跳过；
* `slow_dirs` / `sd_static`（**方向级**）⟹ 只能由**逐方向**消费点读
  （`_strong_keys` 下方 `for dd in (1,-1)`、主 pick 的 `d in slow_dirs`）。
* `slow_T` / `halate_rule` / `sd_temp` 是**带温度门**的（温度相关者不能进
  预组装快路径，必须让 `is_dyn` 为真）。
* **配对级规则只判 `b["red"]` 会漏掉一半有序对** ⟹ 凡形如 `b["red"] == X`
  的恒慢规则，都要问"X 落在 a 槽时怎么办"。

### 3.3 断言纪律要点

* 标准只锁**化学事实**（pH、总产量、特征步），不锁引擎输出、不锁中间路线；
* `changed` / `degree` 等语义位移量**不作门槛**（`discipline.md` §三）；
* 数据库缺口与引擎缺陷**分开记账**；
* 回退先比 pH + 物种量 + `eq`，再比方程——**化学一致的一律改断言不改引擎**。
