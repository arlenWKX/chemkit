## 1. 五分钟上手

**chemkit** 是一个**纯标准库**（Python ≥3.12，无第三方依赖）的水溶液反应引擎：
输入"往水里加了什么"，输出**最终物种分布、pH、净反应方程式、反应程度**。
设计目标是**把化学事实（平衡、动力学硬事实、相变）如实算出来**，而不是套教科书简化式；
数据与引擎严格分离。

```bash
python tools/dev.py suite            # 全量回归（1378 例，约 1–2 min）
python tools/dev.py suite J05 NR23   # 只跑子集（按名字前缀）
python tools/dev.py case  EU01       # 单例深探：步表 + 账本净差 + 两版净方程 + 断言
python tools/dev.py eqcheck          # 用例期望方程式的精确守恒（必须 0 违规）
python tools/quick.py NR23 NR108     # 子集快跑，失败项写入 _fails.txt
```

**目录**

| 路径 | 放什么 |
|---|---|
| `chemkit/` | 引擎本体：`data.py` 加载器 · `candidates.py` 候选生成 · `engine.py` 走步/记账 · `speciation.py` pH 与 SIT · `equations.py` 净方程 · `testsuit.py` 用例执行 |
| `chemkit/data/*.json` | **唯一事实源**（热力学、Ksp、pKa、配合物、电对、用例） |
| `tools/` | 诊断与批处理工具（`dev.py` 是总入口，其余见 `agents/tools.md`） |
| `agents/` | 本项目的工作文档：`handoff.md`（本文件）· `log.md` 历史 · `lessons.md` 经验 · `discipline.md` 纪律 · `tools.md` 命令手册 |
| `docs/` | 面向使用者的文档（架构 / 数据 / API / 性能 / 局限 / 测试） |
| `logs/` | 运行产物（套件留档、单例日志），不入库 |

**开关**（环境变量，括号内为默认）

| 变量 | 作用 |
|---|---|
| `CHEMKIT_SIT`（开）| 离子强度层：`logK(I) = logK° + Δz²·A√I/(1+1.5√I) + ε·I`；`=0` 回到全 I→0 |
| `CHEMKIT_CL_BETA`（开）| 氯合络合数据 |
| `CHEMKIT_TRACE=1` | 走步轨迹（pick / 冻结 / 解冻 / 微步）—— 排查空转必用 |
| `CHEMKIT_NO_MICRO_FAST` / `CHEMKIT_NO_DRAIN` | 性能借支审计（省了多少 vs 藏了多少，两列一起看） |

## 2. 当前状态（第 300 轮末）

* **版本 `0.6.0`**；套件 **1259/1378** · 辅助 121/122 · `iters` 合计 **30546**
* `eqcheck` **0 违规**
* **本轮主线完成**：`15 CaCO₃+HCl` 活锁根治 —— **3002 → 13 步**，且守恒恢复
  （CO₂ 总量 0.99975 = 气相 0.965308 + 溶解态 0.034442 泡点，pH 3.93 正确）

### 2.1 气体模型（第 300 轮重写，与固相严格同构）

| | 固相 | 气相 |
|---|---|---|
| 相界常数 | `Ksp` | `c_sat = H(T)·p_ext`（泡点） |
| 有第二相 ⟹ 液相钉在 | Ksp 饱和浓度 | 泡点浓度 |
| 存量容器 | `ledger[X(s)]` | `gas_phase` / 呈现键 `gas` |
| 进出 | dissolve / precip | 鼓泡 / 回溶（**双向可逆**） |

* `S_of` **无气体专属分支**（原 `typ=4` 已删）⟹ 互逆 `S_f + S_r = 0` 天然成立
* **`escaped` 已删除** → 改名 `gas`（气相存量）。`escaped` 是"永久删除"时代的
  概念，两相模型里不存在
* `gsup`（投料气体免扫气集合）**已退役**，参数从 `engine.py`/`joint.py` 签名摘除
* 呈现层 `final` / `production` / `consumption` 一律**总量口径 = 溶解态 + 气相**
* **泡点约束谁**：只约束**自产**气体；投料气体用 `cap_eff = max(c_sat·V, 投料量)`
  （把投料也锁进气相 ⟹ 全库 −73 单调恶化，见 `lessons.md`）

### 2.2 相对基准（`19fc30f` 1283/1378 · iters 30406）的 25 例回退已定性

* **20/25 化学真值完全一致**（pH Δ≤0.07、物种量不变）—— 净方程由分步式变
  合并式，**纯呈现差异**，应更新断言，**不许为此改引擎**
* **4 例真变但新模型更对**：`H35`（Ca(HCO₃)₂ 加热：旧 pH 10.85=未分解 →
  新 CaCO₃ 0.997 + CO₂↑ 0.997=正确分解）、`RX12`、`E42`、`K02`
* **1 例 `F21`（锗酸）属数据缺口**，与气体模型无关（三档 `cap_eff` 扫描结果一致）

**概念上仍是半成品的地方**（不是 bug，是设计未完成，详见 §4）：离子强度层只有 SIT
（无 Pitzer 全参数）、多核/聚合物物种基本没有、动力学是"闸门 + 限速"而非真速率方程。

## 3. 架构与改代码前必须知道的约定

### 3.1 三层视图（判"引擎错还是断言错"的第一个动作）

| 层 | 取法 | 性质 |
|---|---|---|
| **账本** | `judge(..., _probe=pr)` → `pr["ledger"]` | 化学真值所在 |
| **净差** | 引擎渲染的 `initial → final` 之差 | 引擎自己的解释 |
| **呈现** | `Reaction(r).consumption / production / final` | **`testsuit` 的 `has*` 只读这层** |

工具：`tools/specdist.py <前缀>` 三层并列。

### 3.2 断言键的两个口径（易错）

* `has` 读**池口径**：`T.pool_ligands`（`Cu²⁺/Sn²⁺/Zn²⁺` 的氯合形态）聚合到锚上，
  物种名下**恒为 0**；
* `has_not` / `has_range` 读**物种级**。
* **要锁具体形态的量 ⟹ 用 `has_range`**。
* **语义位移量（`changed`/`degree`/呈现形态）不作门槛**（`discipline.md` §三）。

### 3.3 走步与三级止震梯子

`pick（按 S 贪心）→ solve_extent（二分求根）→ _exec（唯一记账入口）`。
循环/空转按三级处理：**先联立（`_settle_cycle` → `_joint_fire`）→ 再冻结
（`_freeze`，强驱动键依 X-38 拒绝）→ 最后 `_freeze(tension=True)` 如实记残差**。
微步（`ext ≤ max(X_MIN, 1e-4·x_max)`）双向禁用并等账本签名变化。
**排查空转的固定动作**：`CHEM_TRACE=1` 看 `[pp]` / `[freeze-*]` / `[_exec]` 三类行，
再用 `tools/churnprobe.py`（计数器）与 `tools/osc.py`（净键数 / 最大重复 / 锯齿数）定量。

### 3.4 净方程与"弱池折叠"

`equations.py` 会折叠弱族配体池（`_pool_ligand_flux`）：池内再分布**不算事件**
⟹ `changed=False`、净方程可能只报剩余的小过程。这是 v0.4.0 的既定口径、**不是缺陷**，
但断言不能建在 `changed` 上（判据见 §3.2）。

### 3.5 ⚠️ SIT 的 ε 项符号：一个**未定案疑点**（动氯合数据前必读）

`sit_logK` 的公式与 Δz² 项已核**正确**（`AlCl²⁺` 的 Δz² = −6 ⟹ 条件常数随 I 下降，
与"高电荷 Al³⁺ 被离子氖稳定更多"一致）。但 β 派生候选把 **`eps_rxn` 按负号**施加
（`candidates.py` 的 `-eps_rxn`），而 `[AlCl]²⁺` 的文献条件常数
（**0.477 @ I = 0.5**，相对于 I→0 的 1.33）要求 ε 项**取正**：

| I | 0 | 0.5 | 1.0 | 2.0 |
|---|---|---|---|---|
| 现实现（ε 取负）| 1.33 | 0.11 | −0.22 | −0.72 |
| 若 ε 取正 | 1.33 | **0.445** | 0.28 | −0.06 |

### 3.5 ✅ SIT 的浓度依赖已核对正确（第 294 轮）

`sit_logK` 公式为 `logK(I) = logK° + Δz²·A√I/(1+1.5√I) + ε·I`；**生成方向**
（`M + nCl⁻ → MClₙ`）取 `ε = +eps_rxn`，**解离 / 反向书写**的派生反应取 `−eps_rxn`
（与 SIT 理论的"反应级系数 = −Δε"一致）。用引擎真实候选调 `logK_T` 实测 `[AlCl]²⁺`
（`logβ° = 1.33`、`ε = 0.33`）：I = 0 / 0.5 / 1 / 3 时 logK =
**1.330 / 0.445 / 0.436 / 0.847** —— 与文献条件常数 **0.477 @ I = 0.5** 吻合（Δ = 0.03），
非单调（Δz² 项与 ε 项竞争）也是对的。明细见 [`docs/data.md` §8.1](../docs/data.md)。
⚠️ 第 293 轮曾误报"ε 符号疑点"（我自己的探针传错了方向），已更正并在 lessons 留档。

### 4.3 已否证的修法（别重走）

非氧化还原 `f` 用 `led_v`（−184 通过）· `_pin_pair` 整行 · 「立即反向」冻结 ·
「立即反向」守卫整族（判据 / 位置 / `break` 三者都试过）· `EU01` 两版联立（窄窗无效 / 宽窗更慢）·
「锌酸根乒乓」与「求根器伪根」两说 · 「微步禁用计数」做空转触发器 ·
钉住支路 `C_fix` 含 `He_res`（`He_res ≡ (h−oh)·V`，双重计数）。

**气体侧（第 298–300 轮，共 10 次否证，勿重走）**：
① 气体封顶 `min(c_g,H·p)` 推广到**反应物侧**（三版：−510/坏/−506，抹掉 96% 反应物）·
② `logQ` 符号翻转（−506）· ③ 环内扫气（iters −21.4% 但 11 例化学错：pH 12.37 逸出 CO₂）·
④ 逐腿自洽复核（未触发）· ⑤ `_joint_fire` 单次零净推进判据（未触发——零净推进是跨迭代性质）·
