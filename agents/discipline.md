# 纪律条文（动手前的硬规则）

> 规则式、短。**为什么**这样规定见 [`lessons.md`](lessons.md)；
> 命令怎么写见 [`tools.md`](tools.md)。
> 违反这些条文得到的测量**看起来像"该改动无影响"，实为探针自身失效**。

---

## 一、数据表增改只能走「patch + 新进程」

`dev.py` 模块级已 `import chemkit` ⟹ 在脚本里改数据（自写 JSON 或内存
`T.beta.append`）**对加载器不可见**。可信路径只有一条：

1. `python -m chemkit.testsuit patch <spec.py>`（唯一合法写盘方式，带 JSON 复验）；
2. 用**新进程**测量：`suite` / `case`；
3. 临时改动测完必须复原，并核对 `git status` 干净。

**测量点必须自检**（一行）：确认数据真的进了表（`assert … in {…} for …`）。

---

## 二、测量纪律

* 用例清单取自 `run_case` 的**返回值**；错误文本**逐例单跑**核对——
  读 `RESULTS[-1]` 一类共享索引会错位（曾据此把口径问题误判为模型退化）。
* 包装探针要留意**缓存与预热顺序**；结论须换路径或重复跑确认。
* **一次运行全量结构化留档**后反复读取（`logs/suite-latest.json`）；
  不在生成端截断、不靠重跑换信息。
* **包装/自造口径必须先与引擎同口径对拍**（曾自造 logK−logQ 列，与引擎
  `S_of` 差 18.5，根因是候选的**存储方向**与**打印方向**不同）。

---

## 三、断言纪律（化学是门槛）

* 标准只锁**化学事实**（文献 pH、总产量、特征步），不锁引擎输出、不锁中间路线。
* **语义位移量（`changed`/`degree`/呈现形态）不作门槛。**
* **标准答案可能有错**：先判"化学事实 vs 某次引擎输出的快照"。
* **重裁要能卡掉旧值**：新区间必须**排除**旧引擎值才算加强；把窗放宽到
  把旧值也包进去 = 自欺。
* **反算隐含量**识破"违反物理约束的通过"：如旧 pH 3.2 反算隐含溶解 CO₂
  0.891 M，而 `c_sat` = 0.0344 M ⟹ 1 atm 下不可能（旧值才是错的）。
* **数据库缺口与引擎缺陷分开记账**；不许用改松标准或堆数据互相掩盖。

## 四、发版 / 落盘硬门槛

**两套 pKw 约定都必须全绿**（锚定 14.0 / 未锚定 14.0042）：

```powershell
python -m chemkit.testsuit anchor off; python -m chemkit.testsuit suite; python -m chemkit.testsuit anchor on
```

其余固定动作：`suite`（锚定）、`eqcheck`（0 违规）、
`hess_audit`（0 条不自洽，**必须带温度**）、`hygiene`。
**只有在发版层才跑这一整套**（见 `tools.md` 的分层）。

## 五、锚定 vs 未锚定：到底是什么（易混淆，说清楚）

`chemkit/core.py::pKw_of(T_K)` 用经验式
`v = 4471.0/T_K − 6.09 + 0.0171·T_K`。

| 约定 | 式子 | pKw(298.15) |
|---|---|---|
| **未锚定** | `v` 原样 | **14.004172** |
| **锚定** | `v − (v(298.15) − 14.0)` | **14.000000** |

**关键事实**：`v(298.15) − 14.0 = 0.004172` 是一个**常数**，所以锚定只是把
整条曲线**向下平移 0.004172**（273 K 差 0.004172，373 K 也差 0.004172）。

⟹ **它不是两种理论、也不是两条不同的曲线**，只是"教科书惯例上把
pKw(25 °C) 当作正好 14.0"与"经验式原样输出"之间的**零点选择**。

为什么要两套都测：有些断言（如 `T64 H₂S+2NaOH` 的 S²⁻/HS⁻ 比例）对
pKw 约定敏感到会翻转结论（14.0 → 0.5/0.5；14.0042 → 0.384/0.616）。
**两种约定都过 = 结论不靠零点选择的巧合。**

⚠️ 别把"两套约定"神话成两个模型。看到断言在两套间翻转，说明该断言
锁的是**临界量**，应改锁不敏感的化学事实（见 §3）。

## 六、命名与编号

* `tools/` / `chemkit/helper/` 下的工具**不得与 stdlib 模块同名**
  （它们会被放进 `sys.path[0]`：`inspect.py` 曾直接让 `argparse` 崩溃）。
* 一次性探针命名为 `_probe_*.py` 放仓库根（gitignore），**优先扩展已有探针**。
* 测试用例编号：计划统一为**连续纯数字**（去掉字母+数字前缀）并删除重复用例
  ——未完成。
