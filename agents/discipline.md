# 测量纪律（改数据 / 做测量 / 裁决标准）

> 本文件属于 **AI 侧工作记忆**（`agents/`），不是给使用者看的文档。
> 内容是第 87–93 轮三次弯路换来的操作纪律，以及"Fe³⁺ 族一次成型落地"的
> 输入清单。**动手前先看一眼**——违反这三条的测量**看起来像"该改动无影响"，
> 实为探针自身失效**（本轮为此白跑三轮）。
> 使用者的测试文档见 [`../docs/testing.md`](../docs/testing.md)。

## 一、数据表增改只能走「patch + 新进程」

`tools/dev.py` 在模块级已 `import chemkit`，因此 **`dev.py run` 中脚本内的任何数据
改写（自写 JSON 或内存 `T.beta.append`）对加载器一律不可见**。可信路径只有一条：

1. `python tools/dev.py patch <spec.py>` —— 写文件（带 JSON 复验、CRLF 归一化）；
2. 用**新进程**测量：`dev.py case <前缀>` / `suite` / `perf`；
3. 临时红树测完必须复原：`git checkout -- <文件>` 并核对 `git status` 干净。

**测量点必须自检**（一行即可）：
```python
assert "[Fe(OH)]^{2+}" in {b["complex"] for b in T.beta}   # 数据真的进了表？
```

## 二、逐例核对，别读共享状态

- **用例清单**取自 `run_case` 的**返回值**可信；
- **错误文本**必须**逐例单跑**核对——读 `RESULTS[-1]` 一类共享索引会错位
  （第 87 轮曾据此把"断言口径问题"误判为"模型退化"）；
- `S_of` / `enumerate_candidates` 之类包装探针要留意**缓存与预热顺序**，
  结论必须重复跑或换路径确认。

## 三、化学门槛不得为通过而放宽

标准只锁**化学事实**（文献 pH、总产量、特征步），不锁引擎输出、不锁中间路线。
边界用例（如 `R05b`：0.1 M FeCl₃ pH ∈ [1.5,1.9]，文献 1.7~1.8）用来**当哨兵**，
防止重裁时把窗改松。

## 三点五、发版前硬门槛（第 109 轮实测更新）

**两套 pKw 约定都必须 1296/1296** —— 第 72 轮 X-33 自缓冲禁令落地后，长期挂账的
4 例 Al³⁺ 刀口（F48/T92/NR55/NR169）已消失（未锚定由 1291/1296 变 **1296/1296**）：
禁令让 pH 真正随步长响应，结果不再依赖"起始过碱 ⟹ 幻影路线胜出"的相位。
实测命令（各 ~25 s）：

```
python tools/dev.py anchor off && python tools/dev.py suite && python tools/dev.py anchor on
```

**纪律**：任何引擎改动后都要重跑这一对（本次因沿用旧读数跨了 37 轮才发现变化）。
其余固定动作：`dev.py suite`（锚定）、`dev.py eqcheck`（0 违规）、
`hess_audit.py --T 273.15 --T 363.15 --with-templates`（0 条不自洽）、
`data_audit.py`（硬错误 0 条 / 已裁决 5 条）、`dev.py perf`（与基线逐位对账）。

## 四、X-32 Fe³⁺ 族一次成型落地清单

**性质（第 93 轮裁定）**：纯标准重裁，两类——
**(a) 路线类**（`eq`/`eq_has` 改按实测新路线）：

| 用例 | 补后 pH | 引擎实测净方程 |
|---|---|---|
| R05 | 1.72 | `6OH⁻ + 4Fe³⁺ ⇌ 3[Fe(OH)]²⁺ + Fe(OH)₃` |
| T93 | 1.41 | `Fe³⁺ + OH⁻ ⇌ [Fe(OH)]²⁺` |
| D32/N30 | 1.44/1.45 | 含 `[Fe(OH)]²⁺ + [Fe(SCN)₃]` 的配位-水解竞争式 |
| D47/H26 | 1.39/1.23 | 与引擎一致的**最小整数比**写法 |

**(b) 物种口径类**：`N28`/`T37`/`T33`/`O05` 的"游离 Fe³⁺ ≥ 1.9/0.9"——
实测 `N28` 游离 Fe³⁺ **1.8465**、`[Fe(OH)]²⁺ 0.1379`、`Fe(OH)₃ 0.0156`，
**总 Fe(III) = 2.000（质量守恒）** ⟹ 氧化本身仍定量，失败只因断言只数游离态。
改法：改数**总 Fe(III)**（或按水解比例下调阈值）并在 `note` 写明文献依据。

**数据**：`beta.json` 插入 `[Fe(OH)]²⁺`（logβ₁ = 11.8；Baes & Mesmer 1976，
`log*K₁ = −2.19`），锚串 = `[Al(OH)_4]^-` 条目的 `calibrated` 行。

**验收**：新进程全量套件（目标 1296/1296）+ `perf` 指标 + `R05b` 哨兵；
未锚定约定下 4 例 Al³⁺ 刀口（F48/T92/NR55/NR169）是否随之转绿一并报告。

**回归参照**（第 75/76/77 轮文件级实测，勿重复发现同一件事）：
单独补数据 1267/1295；成对（数据 + n 次根指数）1273/1295；再加 `hyd_map` 去重
1258/1295；只补 `[Fe(OH)]²⁺` 1277/1295（18 例全 Fe³⁺、零 Al³⁺ ⟹ 破坏面按阳离子可加）。
