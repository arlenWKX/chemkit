### 采用：结构判据（净变化向量）

候选的非 H/O **净变化向量**必须非零：

```python
for sp in set(c) | set(p):
    if sp in (WATER, H_ION, OH_ION):
        continue
    if abs(c.get(sp, 0.0) - p.get(sp, 0.0)) > 1e-12:
        return True                     # 有净变化 ⟹ 是化学反应
return False
```

**显著性阈值必须用绝对 ε 而不是 `tol`**（实测回归 1 条）：`tol` 随方程
尺度放大（0.07 mol 体系上 tol=3.6e-5），会把 ZN5 的 2.1e-6 mol 真实水解
（`Zn^{2+} + H_2O <=> [Zn(OH)]^+ + H^+`）误判成"无净变化"⟹ 拒绝 ⟹
回退到不平衡态。同集合不同量是合法的（`{A:0.6}→{A:0.4,B:0.6}` 即 A→B），
所以判据必须看**量**而不是物种集合。

## 三、T1：`dist_charge` 的 M·V 量纲错误（★★★★★ 根治）

### 病灶（三层实测证据）

`charge_pH` 的 `_F(pH) = V·h − V·oh + fixed + Σ dist_charge(...)` 里，
`fixed`/`V·h`/`z·V·cm` 全是 **mol**，而 `dist_charge` 在 V≠1 时返回
`M·V·(sz/sw)` = **mol·L**。`M` 来自 `rec[2] += m`（账本**摩尔量**，
与 `fixed += z·m` 同源），所以正确值就是 `M·(sz/sw)`。
`if V != 1.0` 分支使 V=1 时数值恰好正确 ⟹ **1378 例里 1370 例 V=1
全部隐身**（这正是 300 轮没发现的原因）。

### 第二处病灶：`_FD` 里的内联副本

`charge_pH` 的 fast 路径（阻尼 Newton）同时求值 `_F` 与 `_FD`，而
`_FD` 里有**自己内联的** `tot += M * V * mq`（L522）。只修
`dist_charge` 会让两把尺子差一个 V 因子 ⟹ Newton 收敛到错根。
实测：同浓度 GaCl₃+4NaOH 在修了 `dist_charge` 后**仍然**给出
pH 12.95/10.40/6.85（V=0.1/1/10），而手工复算 `F/V` 三条曲线
**逐点相同**、根应唯一在 10.40。

### 修法

两处都改为 `M * (...)`（不乘 V）。`V` 参数保留（调用方签名稳定），
但不再进入返回值。
