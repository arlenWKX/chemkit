# 第 286 轮 · 根治 `S_of` 气体分支的活度口径（`S` 不反对称）+ 一条缺失的动力学硬事实

## ① 症状：**同一条净反应的两个书写向给出不同的 `S`**

第 285 轮把"立即反向守卫"整族否掉后，`TE1` 的残差仍在：**账本明明已经中和到正确终态
（`He = 0`）却仍留 0.2950**。既然不是走步守卫，就要问"这一步的 `S` 是谁给的"。

新写的 `tools/sprobe.py`（气体/候选级 `S_of` 分解）在 1:1 缓冲态
（`NH₄⁺ = NH₃ = 0.005`、pH 9.25、`He = 0`）上枚举**引擎自己**的候选：

    NH_3 + H^+ -> NH_4^+   (logK +9.25)   S = +0.0000
    NH_4^+ -> NH_3 + H^+   (logK −9.25)   S = −0.2953      ⟸ |S_fwd| ≠ |S_rev|

**这是热力学硬性违反**（同一条净反应反写必须 `S → −S`），比"某例残差大"严重得多：
引擎自己的 `S_fwd` / `S_rev` 比较、震荡判据、走步方向全建立在这个量上。

## ② 机制：`plan` 按**箭头侧**分派标准态（三处一起看才成立）

1. `engine.py` 第 349–355 行：**反应物**一律发 `typ=2` ⟹ 走 `_logc_of`，`a = c/c°`；
   第 361–362 行：**气体产物**发 `typ=4` ⟹ 走气体分支；
2. 气体分支的式子是 `a = max(min(c_g, H·p_ext), A_GAS)`；
3. `candidates.py` 第 26–36 行写明 `A_GAS = P_RES_KPA/P_STD_KPA = 1.0/101.325 = 0.0098692`
   是"**自产气体逸出后**惰性环境的残余分压约定" —— 即"**气体不在账**"时的回退值。

数字逐位吻合：

    log10(A_GAS) = −2.00579      log10(0.005) = −2.30103      Δ = +0.29524
    实测不对称量 ±0.2953                                        ⟹ 同一个数

`max(·, A_GAS)` 把**回退值**用成了**在账溶质的活度下限**：只要 `c_g < A_GAS` 就把活度
**抬高**到 `A_GAS`。`NH₃` 作产物时走该式（被抬高）、作反应物时走 `_logc_of`（真实浓度）
⟹ 两侧不同口径。

> ⚠️ **中途一次自造口径的教训**：`sprobe.py` 第一版自己算了"手工 `logK − logQ`"列，
> 与引擎 `S_of` 差 **18.5**。根因是候选的**存储方向**与**打印方向**不同 —— 那列是我的
> 错，不是引擎的。删掉后工具只打印引擎自己的值。**自造口径必须先与引擎同口径对拍。**

## ③ 修法 + 为什么切在这里是对的（不是换公式凑数）

    H = henry_of(T, s, T_K)
    c_g = ledger.get(s, 0.0) / V
    if H is not None and c_g > X_MIN:
        a = min(c_g, H * p_ext_kpa)   # 在账：真实溶解量（泡点以上已被扫气移走）
    else:
        a = A_GAS                     # 不在账 / 痕量 / 无 Henry 数据：逸出残余分压

**语义论证**：`A_GAS` 描述的是"气体**已离开溶液**"这一状态（`p_res/p°`），只对**不在账**
的气体成立；在账气体是**溶质**，其活度按库内一贯口径就是 `c/c°`。这条口径本身是
**有意设计**而非疏漏 —— `candidates.py` 第 29–31 行：外加供给的可溶气体试剂（氨水、
氯水）必须按**溶质活度**，否则 `AgCl + 浓氨水` 这类络合溶解全部被低估。
修后两侧同口径 ⟹ `S` 反对称。判据是**量纲/语义归属**（`1/101.325` 是分压比，不是浓度），
不是数值拟合。

## ⑤ 两个翻红的处置 —— **都不是气体口径问题**

* **`Sn11`（`SnCl₂ + 0.5 M HCl`）**：引擎开始执行 `2H^+ + Sn^{2+} -> H_2 + Sn^{4+}`
  （4.9%，`Sn⁴⁺ = H₂ = 0.004958 mol`）。热力学上它**确实自发**（pH 0.31 时
  `E_cell = +0.168 V`）⟹ **不能靠热力学反驳**。真因是**缺一条动力学硬事实**：
  Sn²⁺ 是**温和**还原剂（还原 Fe³⁺/Hg²⁺ 等强氧化剂），**不还原 H⁺**；
  SnCl₂/盐酸 是分析化学的标准稳定储备液（用例自己的注就是这个）。
  处置：按**同族先例** `Ge(IV)/Ge(II)`（`couples.json` 已注
  `closed_with_ox: ["H^+"]`，注文"Ge 在低位时对 H⁺ 的氧化有动力学势垒"）
  给 `Sn(IV)/Sn(II)` 补**同一注解**，依据写进该条的 `note`。
  **旧地板一直在替这条注解干活** —— 地板一拆，缺失的注解立刻显形。
* **`Y09`（`PbS + 稀盐酸`）**：引擎执行**痕量**溶解（56 个几何衰减微步：
  0.000813 / 0.000467 / 0.000332 / 0.000276 …，合计 `H₂S = 0.005004`，
  游离 `Pb²⁺ = 6.7e-5`）。原断言 `eq: null` + `changed: false`（"完全无反应"）
  **过强，且此前之所以成立靠的正是缺陷**（旧地板把 H₂S 活度抬高 +0.29524 才压住驱动）。
  **化学核对（独立可算）**：`K = [Pb²⁺][H₂S]/[H⁺]² = Ksp/(Ka1·Ka2)`，教科书
  `Ksp ≈ 1e-28`、`Ka1 ≈ 1e-7`、`Ka2 ≈ 1e-13` ⟹ `K ≈ 1e-8`；引擎终态
  `6.7e-5 × 5.0e-3 / 4 ≈ 8.4e-8` —— **同数量级** ⟹ 痕量幅度可信。
  而"PbS 不溶于稀盐酸"本身是**幅度判断**（否则定性分析用它分离 Pb 不成立），
  且加稀盐酸**确实能闻到 H₂S** ⟹ 痕量溶解是真的。
  处置：改成**量级上界** `has_not: {"H_2S": 0.05}`（= 投料 1 mol 的 5%），
  仍能抓住"将来退化成主体溶解"。

## ⑪ 方法教训（对应 `lessons.md` 新增条目）

1. **物种活度是状态量，不能按"写在箭头哪一侧"分派标准态**（D17）。改 `plan` 的
   `typ` 或任一 `typ` 分支的公式后，**第一件事是把代表性反应两个书写向都枚举、
   核对 `S` 反对称** —— 比跑全量便宜，且能直接抓住这类缺陷。
2. **"下限/回退"类常数先拆定义式验量纲**（D18）：`A_GAS = 1.0/101.325` 一眼是
   **分压比**。凡见"同一常数既作回退值又作钳位限"，先各写一遍它的定义式。
3. **任何"压住驱动"的数值约定都在替缺失的化学注解干活**：拆掉 `A_GAS` 后，
   **同一轮内**立刻翻出两类被它掩盖的缺口（`Sn11` 缺动力学注解、`Y09` 收敛未走完）。
   移除这类约定前要**预测会翻出哪些注解缺口并预留工作量** —— 把翻红当回退理由是错的。
4. **判别锚 ≠ 化学护栏**：`GS5` 是判别锚（有修/无修翻转），`Y09` 的 `has_not` 是
   护栏（两边都过、只防退化）。**写 DB 注与 handoff 时必须标明是哪一种**，
   不能拿护栏充判别证据。
5. **性能数字要做"同用例对照"**：`chemkit.testsuit perf` 比的是**受控基线**（上次刷新的用例集），
   用例一变就会把 `n` 这类纯规模量混进"位移"清单，且分不清"用例变多"与"引擎变慢"。
   本轮靠 `chemkit/helper/perf_diff.py` 把 `+24%` 墙钟**精确定位到单例** `EU01`。
6. **测试库改动用 `--check` 先验证再 `--write`**，且新锚要**独立于引擎可推**
   （本轮 `pH = pKa` 与 `Ksp/(Ka1·Ka2)` 两条都是手算可得的判据）。

# 第 289 轮 · `EU01` 空转**结案**：触发点④的"有利到限"分支即张力现场 + `_freeze(tension=True)` 落地

## ① 先否证本轮第一版实现（微步禁用计数触发）

第 288 轮收尾时的设想："churn 键被反复**微步禁用**，这就是现成的触发器"
（`MICRO_FREEZE_N=8`，禁用计数到 8 → `_settle_cycle` → `_freeze`）。
**实测否证**（`tools/churnprobe.py EU01`，2819 → 2790 步，几乎没动）：

* 触发只在**第 7 步**打中一次，冻的是 `NO₃⁻/NH₄⁺×Zn` 对——那是走步开局
  正常的"强驱动但根极小"候选，**不是震荡对**；
* **主震荡对结构上打不中**：`2H⁺+2Eu²⁺→H₂+2Eu³⁺` 的 `x* ≈ 1.1e-5` **越过**
  微步界 `1e-4·x_max = 4.9e-6`（2.3 倍）⟹ 它每次都**被执行**（微步执行
  分支），从不进入微步**禁用**分支 ⟹ 禁用计数器对它永远是 0。
  **"微步禁用是现成触发器"的前提对该对不成立。**（实现已整段回退。）

## ② 决定性测量（`CYCLE_AUDIT` 钩子 + `tools/cycle_audit.py`）

触发点④（净质子循环跳步）在 EU01 的 2790 次迭代里**把循环识别了 2730 次**：

    出口分布：有利到限 2729 次 / 跳 1 次
    hist=27  s0=+8.65  out=有利到限 hi=6.1e-05   腿 S = +10.05 / +7.25
    hist=2780 s0=+3.46 out=有利到限 hi=0.00233   腿 S = +8.34 / −1.26 / −0.22

循环是 **Eu³⁺/Eu²⁺ 电子穿梭**（`2H⁺+2Eu²⁺→H₂+2Eu³⁺` × `Zn+2Eu³⁺→Zn(OH)₂+2H⁺+2Eu²⁺`，
质子中性 ✓）。2729 次都落在同一出口："**S_net 到物料上限仍为正 ⟹ 交给走步逐步吃
（不越界）**"，而 `hi = min(腿物料上限/权重)` 被**穿梭物种的瞬时量**封在
1e-4 量级 ⟹ 跳与不跳一样慢 ⟹ 走步以 ~1e-5/步 爬 2815 步。
**"同一个循环被反复识别、反复不处置"本身就是走步在宣告"我解不动它"**
——这就是张力现场，不需要新阈值去"发现"它。

## ③ 修法（方向 (b)：冻结豁免 × 张力分类，守卫收窄而非拆除）

1. `_cycle_jump` 拆成 `_cycle_disposition`（纯判定，返回

   且至少一条腿 `|S| > FREEZE_MAX_S`（**RX13 保护**：腿都弱的近平衡循环
   不算，第 262 轮误冻教训），即构成张力证据；
2. 处置序不变（X-38）：**先 `_settle_cycle` 问联立**，解不出才
   `_freeze(keys, "cycle-tension n=8", tension=True)`；
3. `_freeze` 新增 `tension` 参数：**仅此时**允许冻强驱动键——此时"强驱动"
   不是"还能解"而是**张力本身**（Ag32 型，引擎对该族的既定答案就是冻结）。
   键同时入 `_tension` 集，`_try_revive` **豁免解冻**（防 §1.20 实测的

4. **诚实性由既有口径保证**：`resid_live_ok` 对 |S|>0.1 的冻结键**照计

# 第 290 轮 · 固相钉住估计落地 + **He_res 双重计数根治**（铝酸根半中和族 6 例翻绿、零翻红）

## ① 目标与病灶链

P0 第一优先项：H45 铝酸根/Al(OH)₃ 定量分配。r288 实测链：
`H45`（Na[Al(OH)₄] 1 + HCl 0.5）终态**走步 0 步**、`exit=no-cands`、
0.5 mol HCl 闲置在 He、账本铝酸根=1、pH 13.05。根因：
`_buffer_titration` 虚拟滴定已正确把 He=0.5 吸收成虚拟账本
（铝酸根 0.5 + Al(OH)₃(s) 0.5），但分支 4 弱碱式把虚拟 Al(OH)₃ 当
惰性旁观者 → pH 13.045 → 沉淀候选 S=−0.91<0 → 永不启动。
数据无锅：pKsp(Al(OH)₃)=33.0 + logβ₄=34.5 → logK=+1.5，与 beta 条目
calibrated 注记逐位一致。第 278–280 轮 `_pin_pair` 三版全否（§1 已记），
本轮不重走。

## ② 修法（speciation.py，估计层"固相钉住"接管支路）

固相与其含氧酸根**同时显著在账**（都用引擎自己的尺子 ANN_MIN_EXTENT）
时，分支 4 弱碱式的前提（"该碱是溶液里唯一的碱"）不成立——游离酸根被
固相钉死在 `[A]=β_k·Ksp^(1/x)·oh^n`。只把该酸根自己的那一项换成钉住值，
与账本电荷平衡联立成**单未知量**方程
`f(u)=C_fix+h−oh+Σz·10^(lgA+n·u)=0`（单调降、二分 60 次，
模块级 `_pin_ox_pH`）。lgA 过 SIT（`sit_logK`/`sit_fixpoint`）到与
`S_of` 同尺（**关键发现**：`S_of` 的物种活度就是浓度、SIT 全在
`logK_T` 里，钉住系数不过 SIT 则与 S 差 0.05 而永不启动）。
普查工具 `tools/pinox_census.py`：82 例命中前提（71 PASS / 11 FAIL），
`16`/`LT8` 不命中（负对照安全）。

## ③ ⭐ 根源修正：C_fix 的 He_res 双重计数（W10 停摆案）

第一版 `_Cfix = He_res/V + Σ未钉住电荷`。**实测否证于 W10**：
走步中途 He_res=−0.079（氨合步按"消耗 2H⁺"口径簿记）与氨合电荷
+0.081 对消成 C_fix=0.002 → 钉住 pH 11.29（真值 12.9）→
锌酸根被判过饱和、前进根=0 → 走步 5 步停摆（resid 1.596，翻红）。
**根因**：引擎不变量 `Σ_账本电荷 + He_res = 0` 与电中性
`Σ_账本 + (h−oh)·V = 0` 联立 ⟹ **`He_res ≡ (h−oh)·V`**——He_res 与
f(u) 的 `h−oh` 项是**同一池游离质子的两套记账**（质子簿记口径 vs
浓度口径），相加即双重计数。X-45（第 151/152 轮）在通用分支早已确立
"两套记账只能竞争、不能相加"，钉住支路初版重犯了它。
**修法**：`_Cfix = 0.0` 起算，去掉 `He_res/V`（H45 类 He_res=0 时
两式本就相同，故对目标族零影响）。W10 随即**解停摆**：

1. **`Sn` 族掉出池**：新值 β₁=+1.42 ≥ 1.0 ⟹ `[SnCl]⁺/[SnCl₂]/[SnCl₃]⁻` 整族

2. **`logβ<1.0` 不是"弱配"的正确判据**：它把"弱到看不见的络合"当事件，而
   `CaCl⁺(−1.0)`、`MgCl⁺(−1.0)`、`NiCl⁺(−0.4)`、`FeCl⁺(−0.1)` 这类**任何一种
   金属氯化物溶液里都该是形态分布**的物种，被当成了"浓介质生成/稀介质分解"的
   事件。正确判据应按**"是否为同一种盐的逐级形态谱"**（`nu` 谱 / 电荷 / 配体
