## 三、T4：`LT4`/`LT8` 断言窗重裁（待办 2）

   `{[Al(OH)₄]⁻: 0.1/0.5, Na⁺: 同}`，无 `Al(OH)₃` 析出 ⟹ "无固相"前提成立）。

## 四、patch 工具的三处切片陷阱（用户"两头抓"指点后收束）

改长 note 连续踩三步，全部由 `patch --check` 拦下（未污染数据）：
1. `json.dumps` 输出**自带首尾引号** ⟹ 替换后叠成 `"note": ""第…`；
2. 源文本定位锚串时 `find('\n },')` 取到行尾**含闭引号** ⟹ 切片须 `e-1`；
3. dumps 输出嵌进 spec 源码再 `exec`，`\"` 被 Python **二次解析**成 `"`
   ⟹ 匹配 0 次。

**教训**（已入 lessons.md §3）：锚串=引号内源码；新串=`json.dumps(...)[1:-1]`；
写完 spec 先 `--check`。同时明确**两工具分工**：`JsonDoc` 取值/构造锚串
（精确、不怕排版），落盘必须走 `testsuit patch`（唯一合法写盘方式，
带 JSON 复验）——不绕过纪律条文一。
