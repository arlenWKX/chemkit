## 第 296–305 轮（全文：[`archive/log-296-305.md`](archive/log-296-305.md)）

（15 例「不反应锚」翻红）、`[SnCl]⁺` β 修正后掉出池推翻 292 轮结论。

快照断言（断言不许锁引擎输出，只能锁化学事实）。

**298/299** `15 CaCO3+HCl` 活锁完整机理链（3002 步做一件事）：**最终答案
化学全对**（pH 3.93、CO₂ 落泡点）⟹ 纯性能缺陷。6 次修复尝试全部被实测
否证，共同特征：都在单次行为上找缺陷，而病是跨迭代循环（落实↔拆回）。

`c8f7044`：1280/1378 · iters 30546）。

真值**，引擎无罪。同期完成工具链收敛（唯一入口、删 `tools/`、建

### 第 309 轮（v0.6.6）：气液相平衡并入统一候选求解

**根因**：旧实现把气相存量置于统一账本之外，只能在每轮化学反应后调用
`_equil_gas_phase` 扫描修正。第 308 轮单例慢约 150 倍的实验是旧 `S_of` 内的
`a=min(n/V,c_sat)` 活度截断，不是普通相候选；它不能否证统一处理。性能断崖的
暴露点是**相变量体外**，不是普通平衡天然昂贵，也不是成核/传质速率（后者仍是
独立未建模边界）。

**根治**：新增 `_phase_candidates`，以 `X(aq) ⇌ X(g)` 生成 `Cand(kind="gas")`；
气相 `X(g)` 进入统一 `ledger`，复用 `S_of → solve_extent → _exec`，微步快通道
与真实微步同样接纳 `gas`。删除 `_equil_gas_phase` 和步后扫气循环；收尾再把
`X(g)` 聚合为公开 `r.gas`，保持公开结果及守恒语义。`S_of` 快路径按 Henry
定律计算并依候选书写方向定号；独立正反 Cand 探针验证 `S_f+S_r=0`。解析器
使 `X(g)` 与 `X` 元素组成一致，纯换相不进入狭义化学净方程。

**断言裁决**：`E14` 旧 HClO 阈值锁的是“Cl₂ 全反应后步后扫气”的非平衡中间态，
活平衡残差 **1.189 → 0**；按 `x³/[Cl₂(aq)]=K` 重裁为 `[0.01,0.014]`。
`N15` 改为实际守恒净方程。定向 `E14/N15` 2/2，辅助 123/123。

**全量验收**：
- 锚定：1286/1378，辅助 123/123，52.3 s / 4 workers，总 CPU **169.74 s**，
  iters **26165**；基线 1286/1378，CPU **168.73 s**，iters **31326**。
  即 CPU **+0.6%**、iters **−16.5%**，`new_failures=[]`、`new_passes=[]`。
- 未锚定：1286/1378，辅助 123/123，51.4 s，CPU 166.46 s，iters 26199；
  结束后确认 `anchor status=on`。
- `case 15` PASS（pH 3.93）；泡点、压力、回溶、关气相开关、碳守恒及方向
  探针全过；`eqcheck` **0 违规**；输出守恒 **31 → 28 条分步方程违规**，
  净方程 0。92 个套件失败均为既有登记项，不能称全套全绿。

结论：按“无显著退化则统一”的判据保留统一实现。
