## ⚠️ 从 `START.md` 开始

**`START.md` 是唯一必读入口**。它短（一屏）、给出当前状态与"本轮该做什么"。
其余文件按需查，不要通读——`log.md` 有 580 KB，通读会淹没上下文。

| 文件 | 管什么 | 什么时候读 |

## 三条铁律（其余都是推论）

1. **先测量，后动手。** 任何"我觉得根因是 X"必须先用探针/手算验证；
   没验证就改 = 赌。本项目反复出现的失败模式就是"自以为找到根源"。
2. **一个物种、一套规则。** 不对称（同为 CO₂，投料与自产两套算法）
   几乎总是"两个物理量被当成一个"的信号 ⟹ 找对称的根因，不加分支补丁。
3. **化学是门槛，引擎输出不是。** 断言只锁化学事实（pH、总产量、特征步）；
   `changed`/`degree`/呈现形态是**语义位移**，不作门槛。

## 写文档的自约定

* **只写"下次能省时间"的东西**：现象 + 实测数字 + 结论，不写心理活动。
* **数字必须可复核**：写清命令/用例名/探针名，别人能重跑。
* **不确定就标明"疑似/待验证"**，不要混进结论。
* **收尾必写**：每轮结束更新 `START.md` 的状态段与待办。

## 与别的目录的边界

* `docs/`：**给使用者**的文档（架构、API、数据、测试、性能、局限）。
* `chemkit/`：引擎与数据。`chemkit/data/*.json` 的增改**只能走 patch**。
* `chemkit/helper/`：审计/开发工具（不参与引擎运行时）。
* `chemkit/testsuit.py`：**唯一的测试入口**。
