## 0.6.2

**修正三条高于真值的断言**（`T25` NaClO+CO₂、`T104`/`Y12` Ca(OH)₂+CO₂）。
引擎化学本来就是对的 —— 实测终态的反应商 `Q/K` 为 1.026 / 1.052 / 1.081，
且碳、钙、电荷均守恒；是**阈值设得比真值还高**，永远不可能通过。

- 改为**双侧区间** `has_range`（下界 = 0.85×真值，上界 = 1.25×真值）：
  低于下界 = 反应没走，高于上界 = 平衡常数错，两侧都能抓住回归。
- 撤掉这三条的 `eq`（净方程整数比随走步路径连续变化，属于呈现形态，非化学事实）。

化学与性能无变化：套件 **1283/1378**（+3），`iters` 31326 不变，`eqcheck` 0 违规。

## 0.6.1

**化学行为无变化**；本版只收敛开发者工具链，使用者可见的改动如下：

- **测试入口统一为 `python -m chemkit.testsuit <verb>`**（`suite` / `case` /
  `anchor` / `eqcheck` / `patch` / `hygiene` 等）。旧的 `python -m chemkit.testsuit …`
  写法已移除，请改用上面的入口。
- **审计工具移入包内** `chemkit/helper/`（如 `python -m chemkit.helper.eqcheck`），
  不再依赖仓库根下的 `tools/` 目录。
- **新增 `--out FILE`**：把一次运行的输出**同时**写到控制台和文件（含进度行），
  不需要 shell 重定向。
- **失败清单改为逐行可读**（此前 98 个用例名挤成一行）。
- 移除 163 个一次性脚本与历史日志目录。

化学结果不变：套件 **1280/1378**、`iters` 31326、`eqcheck` 0 违规。
