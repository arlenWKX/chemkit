# chemkit 架构设计

水溶液反应判定引擎。输入一批物质（名称 + 物质的量）与条件（体积、温度、外界
气压），输出：是否净变化（changed）/是否化学反应（reacted）/程度（degree 2/1/0）/
净消耗与净生成、初态与终态组成、pH、总净离子方程式、分步方程式、逸出气体。设计目标是**从热力学数据推出反应行为**，而不是维护一张庞大的
反应事实表。

## 1. 模块划分

```
  core.py        化学式解析（H_2SO_4、[Fe(CN)_6]^{4-} 等内部表示）与方程式配平
                 （手写免分数整数消元零空间，v0.3.5 起取代 sympy）
  data.py        数据表加载（Tables）、统一动力学字段展开、Henry 常数温度修正、
                 dhf_of 单一事实源入口（v0.3.5）
  candidates.py  引擎地基：全局常数、Cand 候选对象、logK(T) 三通道、半反应
                 配平、元素周期表级拆盐兜底、Hess 派生候选（v0.3.4 自 engine 拆出）
  normalize.py   投料规范化：投料 → 引擎账本（电离/中和/浓酸分子态）（v0.3.4）
  speciation.py  pH 机器：缓冲滴定/四分支 pH 估计/多级形态分布/强酸再电离（v0.3.4）
  acidbase.py    精确酸碱地基（v0.4.4 新增，**诊断用，未接入主路径**）：
                 质子化族静态表（pKa 连通块 + 最长链定序）、逐级严格分布
                 dist_charge、电荷平衡 pH 解 charge_pH、ledger_charge 校验。
                 已证伪"直接替换 pH 机器"的设想——边界见 §7 F/G
  templates.py   候选宇宙：红氧模板四级缓存 + 三层枚举 memo（v0.3.4）
  engine.py      判定引擎主循环：S 评估 → 二分求解 → 驱动力排序 walk；
                 步执行记账 _exec 闭包（walk 步与联立跳步共用，v0.3.8）、
                 联立触发点（爬行检测）与物种级周转冻结
  joint.py       联立平衡求解器（v0.3.8）：耦合平衡集联立非线性方程组的
                 阻尼 Newton（数值 Jacobian + 非负投影 + Tikhonov 兜底）；
                 三态返回 ok/boundary/fail（boundary = 联立不动点在物理
                 域外——数据张力型爬行的提前冻结信号）
  converg.py     收敛质量基准（v0.3.8）：1218 例残差画像 dump/diff/top——
                 动 walk 语义前的全量差分基线（触发点② idle 精修即被
                 此差分否决后回退）
  equations.py   方程式装配：步骤聚合/中间体折叠/系数有理化（v0.3.4 自 system 拆出）；
                 大系数美化：次要物种移除 + 平衡子空间投影 + 有理重构（v0.3.8）
  system.py      高层实现：Engine 对象（judge/react/system 平级方法，v0.3.6）、
                 Reaction（一次反应结果）、System（连续投料）、react()、共用
                 求解管线 _solve()（三层 API 直落此处，无包装链）
  thermo.py      独立温度模块：事后 ΔT 分析（analyze）+ 绝热耦合求解（coupled）；
                 ΔHf 消费 data.dhf_of（v0.3.5 删除自带副本）+ 逸出气相拆分
  interfaces.py  用户侧唯一门面：公开 API 总入口（纯再导出，无实现）
  testsuit.py    测试套件（独立模块）
  data/          全部化学数据（JSON，唯一事实来源）
```

依赖方向单向：`core ← data ← candidates ← normalize ← speciation/templates
← engine ← system ← interfaces`（thermo 延迟引 engine）。引擎不 import
system；system 只做结果包装与模式开关，不含化学判定逻辑；interfaces 是
纯门面（零实现），承诺跨版本稳定的公开面只有从这里导出的符号。v0.3.3 前
经由 engine/system 访问的符号全部由二者再导出（兼容路径不变）。

### 2.1 统一动力学字段

`couples.json` 中的 `kinetics` 是动力学标记的**唯一书写形式**，语义化、
与引擎内部键解耦：

| 书写形式 | 含义 |
|---|---|
| `ox_closed` / `red_closed` | 该电对作为氧化剂/还原剂方向动力学封闭（如 SO₄²⁻ 氧化性、S(IV) 歧化） |
| `below_T` | 低于该温度（K）反应动力学冻结（如 CO₂/C 需高温） |
| `closed_with_red/ox` | 只对指定搭档封闭（双向，两个配对取向都封闭） |
| `closed_except_red` | 除指定还原剂外封闭 |
| `red_pH_min` | 还原通道的 pH 下限（形态不可达） |
| `h2o_red_oh_min` | 该电对作氧化剂时可氧化水析 O₂，但仅当 aOH ≥ 该阈值（浓碱解锁；如浓碱中 MnO₄⁻→MnO₄²⁻ 制锰酸钾）。引擎据此解除 O₂ 析出恒慢，改由 pH 动态门接管 |
| `ox_pH_max` | 该电对作氧化剂方向在 pH 高于阈值时动力学冻结（方向感知；如 MnO₄²⁻/MnO₂ 的歧化在 pH>14 冻结——锰酸根只在稀/中碱歧化，浓碱中稳定） |
| `rev_gate` | 逆向驱动时的反向闸门 |

加载时由 `data.py:_expand_kinetics` 展开为引擎内部键。**纪律**：只有热力
学无法解释的化学硬事实（钝化、歧化封锁、温度门槛）才允许写动力学标记；
热力学本身能给出的行为一律不得用标记修补。`engine.KINETICS = False`
可整体关闭动力学层，回到纯热力学基线（用于审计标记的必要性）。

### 2.2 晶格阴离子电对派生

电对 `(ox, red)` 的 red 若是某固相 M_xA_y 的 ksp 配对阴离子 A⁻（如
S/S²⁻，而 ZnS/CuS/PbS… 都有 S²⁻ 的 ksp 记录），则 Nernst 代入
`a(A⁻) = (Ksp/a(M)^x)^(1/y)` 直接推出晶格电对 `(ox, red=固相)`：

```
E0' = E0 + K_NERNST_298 · ν_A · pKsp / (n · y)
```

ν_A 为 ox/red 的阴离子计量比（I₂/I⁻ 型为 2，S/S²⁻ 型为 1）。这是热力学
循环而非新数据：`S/CuS` 派生值 0.585 V、`S/HgS` 1.058 V（> HNO₃/NO 的
0.96 V，故 HgS 不被稀硝酸在热力学上深度溶解）、`S/ZnS` 0.112 V 等。

**只派生 S²⁻ 晶格**。硫化物矿石的氧化溶解是独立的化学现象类（湿法冶金、
定性分析分组）；卤素晶格电对（E0′ 普遍 >1.2 V）只会在卤素歧化/归中网络
上叠加无实验对应的边际幻影通道，不派生。派生电对带 `derived_from` 字段
且不继承动力学标记——晶格氧化的动力学由引擎按 `derived_from` 统一赋予
（见 §3.7 的让位档）。

## 3. 引擎（engine.py）

### 3.1 六条公理

1. **候选即平衡**：每个候选反应是一个可逆平衡，logK 由数据表经 Hess 定律
   推出（E0 → ΔG → logK；pKa、Ksp、logβ 直接是 logK；派生候选精确加和）。
2. **pH 连续**：单一带符号质子账本 `H_excess`（正 = 游离强酸 mol，
   负 = 游离强碱 mol）贯穿全程，pH 由缓冲滴定估计，不做分段启发式。
3. **驱动力 S = logK − logQ**：S > 0 正向自发。所有候选在同一 S 标尺下
   竞争，S 最大者优先执行。
4. **执行即平衡求解**：对选中的候选，二分求解平衡程度 x*（S(x*) = 0 或
   反应物耗尽），按限度推进账本。
5. **限度记账**：degree 按限量试剂的转化率分档
   （complete / incomplete / hardly / none）。
6. **单质子账本正则形**：H⁺ 是唯一质子载体；OH⁻ 型平衡一律改写为
   H⁺ 正则形（如 `Mⁿ⁺ + nH₂O ⇌ M(OH)ₙ + nH⁺`），水电离由 `pkw_coeff`
   通道承载温度修正。

### 3.2 规范化（normalize）

投料先拆解为离子/分子账本：可溶盐拆离子、强酸给出 H⁺ + 酸根、
`form:solid` 的难溶物（CuO、Fe₂O₃……）保持分子态不拆。此后引擎只看见
一个 `{物种: mol}` 账本 + `H_excess`。

### 3.2b 拆盐兜底（元素周期表级，`_split_salt_general`）

注册表（`T.cations/T.anions`）是**反应数据的入口**，不是离子"存在"的许可。
未收录的盐（`NdCl_3`、`Ra(NO_3)_2`、`Tb(NO_3)_4`……）由结构性算法兜底电离：

- 阳离子取公式中的金属元素 M（常见水溶液氧化态表 `_METAL_Q`，覆盖全金属
  与镧系/锕系）；
- 阴离子按其余元素组成匹配注册阴离子（组成整倍数，**整除性对全部元素
  强制**——只筛可整除键会把 NO₂⁻ 错配到硝酸盐），或单原子典型价
  （卤/氧/氮/碳族）；
- 电荷平衡 x·qc = y·qa 推出阳离子电荷，交叉验证须落在 M 的常见价态集内
  （`AlCl_4` 被拒；`Na_2O_2`/`KO_2` 由电荷平衡自然区分为过氧化物/超氧化物）。

兜底产出**旁观离子**：正确电离入账但无反应数据即不参与反应——与"未知
整盐静默丢弃"相比保留了电荷与质量守恒。任何元素合法的带电物种投料同样
直接入账（离子存在不依赖注册）。候选序按阴离子名排序保证跨进程确定性
（Python hash 随机化不影响结果）。

### 3.3 候选枚举（enumerate_candidates）

五类候选，每轮主循环重新按存在性过滤：

| § | 类别 | logK 来源 |
|---|---|---|
| 4.1 | 电子转移（电对两两配对，配平 + 电子数归并 + 闸门） | Nernst：n·ΔE/0.05916，ΔH 走 van't Hoff |
| 4.2 | 质子转移（酸解离 / 碱质子化双向） | ∓pKa |
| 4.3 | 沉淀 / 溶解（OH⁻ 型用 H⁺ 正则形） | ±pKsp（含 pkw 修正） |
| 4.3b | 难溶金属氧化物酸溶 M_xO_y + 2yH⁺ → xMⁿ⁺ + yH₂O | 由对应氢氧化物 Ksp 估算 |
| 4.4 | 配位 / 解配（OH⁻ 配体正则化） | ±logβ（含 pkw 修正） |
| 4.5 | Hess 派生候选（如 AgCl + NH₃ 的配位溶解） | 精确加和 |

§4.1 模板构建的三个关键校验：

- **配平池与晶格旁观离子**：常规池 `[H₂O, H⁺]` 配平失败时补配体池重试；
  固相电对成员的 ksp 反离子中，与电对另一方**不共享元素**者入池
  （AgI/Ag 共享 Ag → 取 I⁻；S/PbS 共享 S → 取 Pb²⁺）——它们是该半反应
  的固有参与物种。
- **同元素电对族的幻影排除（`_redox_mix_ok`）**：歧化/归中族（成员共享
  金属，如 MnO₄⁻/MnO₄²⁻/MnO₂/MnOOH/Mn(OH)₂）的配平系统是欠定的，
  零空间中任意取点会混入第三电对的半反应（如
  `5MnO₂+MnO₄²⁻+2H₂O→4MnOOH+2MnO₄⁻`，其 logK=n·ΔE 无意义）。
  注意电子守恒 ≡ 原子+电荷守恒（净电荷 σ 恒为配平约束），靠秩检查无法
  甄别；真正的判据是**张成归属**：配平结果 R 必须能分解为两个半反应
  向量（`_half_vec` 手工构造：金属原子守恒定计量比，O 差补 H₂O、H 差
  补 H⁺）的干净组合 `R = x·va − y·vb`；残余只容许非氧化还原旁观
  （沉淀等，按共享金属氧化数守恒核验），否则为幻影，弃。还原形含氧化
  形没有的金属（晶格电对的游离离子入账，如 S/HgS 半反应需 Hg²⁺）时
  `_half_vec` 返回 None，保守接受。
- **电子数折算**：配平后按半反应系数折算实际转移电子数（lcm 会高估）；
  归中体系从反应物侧折算；混合候选取四向折算的最小正值。

**性能结构（0.3.3 四级缓存体系）**：

1. **温度无关静态层**（`_redox_pair_static`，缓存于 Tables）：电对配对的
   全部重活——配平（`_bal_fast`/sympy）、电子数、ΔH 组装、vs_red 选择性
   闸门、closed_with_red 掩蔽、恒慢标记、慢速温度规则预解析——只依赖
   数据表，全温度点共享，冷启动算一次。93.5% 的电对配对无任何温度规则，
   直接预组装为两种 kinetics 形态的**成品模板**（哨兵：None=该模式跳过 /
   False=动态处理 / tuple=成品），温度层 O(1) 引用。
2. **温度过滤层**（`_redox_templates`，按 (T_K, kinetics) 缓存）：只做
   T_min/only_vs_red/slow_below/halate 歧化温度/pKw 动态阈值的轻量过滤，
   单个新温度点构建 ~25 ms（配平重活已由层 1 承担）。无 pH 依赖慢方向的
   模板（约 99%）连带预构建 `Cand`（meta 全常量），枚举时直接引用。
3. **§4.2–4.4 静态候选**（`_build_static_cands`，按 (Tables, T_K)）：
   候选本体一次构建，主循环每轮只做 `req ⊆ present` 子集过滤。
4. **枚举三层 memo**（`enumerate_candidates`）：层 0 完整结果缓存
   （present 集 + pH 桶 0.1 + 闸门物种浓度 log 桶 0.25）——中间体饥饿
   慢收敛（乒乓/催化循环，迭代间 present 与 pH 不变）直接命中；层 1
   存在性缓存（present 集 + 浓硝酸标志，与 pH 解耦）——pH 桶漂移的
   沉淀转化类仍命中；层 2 动态闸门（pH/浓度随迭代变化，不缓存）。

主循环其余降载：纯二分的浮点饱和早停（60 次迭代超出 double ~52 bit
分辨率后的空转消除）；`_buffer_titration`/`estimate_state` 分支 4 的
静态量按 T_K 缓存并在账物种遍历。整体效果：1378 用例全套 2 min →
36 s，均值 79.7 → 28.3 ms。

**性能结构（0.3.4 主循环降载，数值路径与 0.3.3 bit 级一致）**：

5. **慢标注采样节奏记忆**：慢通道永不可达显著量的体系（FeCl₃+SCN⁻ 类）
   原实现 `slow_seen` 恒 False，每迭代对全部慢候选重解 12 次二分
   （Fe31 实测 1209/1814 次 solve_extent 来自此路径）。负结论按
   (key, dir) 记忆，距上次评估 ≥32 迭代或其间发生步量 ≥0.01 的实质步
   才重评；收敛终局（evals 空转 break 前）统一复核一次保证终态标注
   不漏报。FeCl₃+KSCN 族 830 → 590 ms。
6. **爬行收敛窗口几何外推**（walk 级）：非精确周期的不规则慢收敛
   （Hg₂(NO₃)₂+Hg+HCl 的 7 键不规则循环）按 40 步窗差的 L1 范数等比
   衰减 ρ 外推几何尾部一次补齐（D 为平衡步计量的线性组合，缩放仍
   原子/电荷守恒）。三重守卫：ρ∈(0.25, 0.85)、净/毛比 n1 ≥ 0.4×窗内
   步量和（纯爬行≈1；正逆对消的震荡窗≪1——Ag32 曾被 9× 外推沿震荡
   方向冲出物料守恒，此守卫即为其修复）、倍率封顶 4×。外推失准由
   不动点两侧 S 变号自纠回（既有自校正）。Hg2_1 1483 → 515 ms
   （697 → 497 步）。
7. **热路径查表合并**：S_of 的项执行计划按 Cand 缓存（项类型分类只
   依赖数据表，求值只做查表与算术，项序与原逐项分支一致 ⇒ bit 级
   等价）；浓度对数 logc 两级缓存（候选评估循环账本不变期跨候选复用；
   二分 f 间仅 changing 物种失效）；estimate_state 物种角色表 /
   _buffer_titration 堆构建角色表（每物种 1 次 dict.get 取代 4–6 次）；
   logK(T)/Henry/pKw 纯函数值缓存。整体：均值 28.3 → 24.5 ms，
   最值 1.74 → 0.59 s，>50 ms 130 → 120 例。

基准测量纪律（bench.py）：计时区禁 GC（模板缓存 ~70 万存活对象，
gen-2 全量回收数百 ms 会随机砸进单例计时——3.3.0 报告的 PH09 445 ms
即此噪声，隔离实测仅 10 ms）。

**电对配对配平快路径（`_bal_fast`）**：电对两两全对枚举配平（每温度点
~3 万次）曾是最大热点（sympy 零空间每次 ~1.2 ms；v0.3.5 起零空间本体
已换手写免分数整数消元，每次 ~0.03 ms，差分验证 33401 次 bit 级一致）。
常规电对的配平结果是
两个半反应的**电子 lcm 组合**（教科书标准方程），可用整数运算 O(1) 构造：
`s_a·half_a(还原) + s_b·half_b(氧化逆转)`，电子净零、H⁺/H₂O 自然对消、
归一化到最小整数比。三个等价性约束（A/B 全对验证 0 失配）：

- 四个端点物种均不属于自由池 {H₂O, H⁺}（balance() 把同时出现在 free 池
  与指定侧的物种锁定在指定侧，半反应组合可能把它消到另一侧）；
- 四端点元素与 {H, O} 并集 ≥ 4（零空间维 = 6 − (元素行 + 电荷行) = 1，
  解唯一；单元素族——卤素/氮/硫歧化网络——欠定，走零空间组合搜索）；
- 同元素电对族（same_elem）走零空间 + `_redox_mix_ok` 幻影校验。

快路径命中 ~65% 的配对；零空间本体的整数消元重写 + 元素字典只读共享
（260 万次 elements_of 免重建）把静态层冷构建从 ~20 s 压到 ~3.2 s；
半反应缓存（`T._half_pairs`）跨温度点共享；三件静态产物常驻内存
（v0.3.6 移除磁盘缓存设计：引擎面向长期运行，一次构建跨判定复用，
冷启动优化与稳态吞吐的主次关系被 0.3.5 的磁盘缓存摆反了）。

闸门分两层，必须区分：

- **选择性闸门**（`vs_red_E_max`、`c_min/c_max` 浓度形态闸门）：描述产物
  选择性或介质形态，是化学事实，**不属于动力学层**，KINETICS=False 时
  依然生效；
- **动力学闸门**（`T_min`、`only_vs_red`、`rev_gate`、`red_pH_min`）：
  由 KINETICS 总开关控制。

动力学慢标记有三个层次（语义截然不同，勿混用）：

| 层次 | 语义 | 行为 |
|---|---|---|
| `slow`（恒慢） | 无限时间也不可观察地慢（如 O₂ 氧化酸性 Mn²⁺） | **不执行**，可达显著程度时标注 `annotations: ["slow"]` |
| `slow_dirs`（方向慢） | 模板某方向慢：静态（`sd_static`，如卤素经 XO⁻ 的歧化第二步）、低 pH 侧（`sd_ph`，碱催化解锁）、高 pH 侧（`sd_ph_hi`，来自 `ox_pH_max`） | 同 slow，按 pH 动态判定 |
| `deferred`（让位档） | 慢但可观察的过程（晶格氧化：PbS+H₂O₂、CuS+热硝酸、生物浸出），慢于同固体的离子交换 | 有快候选竞争时**让位**；无快候选时**照常执行**并标注 slow。物理图景：浮选活化 ZnS+Cu²⁺→CuS 是快离子交换，矿石氧化才是慢破晶格 |

另有一条物种级动力学硬事实内建于 `_slow_flag`（与 H₂ 水溶液惰性
同类先例）：**单质硫作还原剂在 T<370 K 的水溶液中恒慢**（升华硫在水中
无限期稳定；S+热浓碱歧化、S+沸腾浓硝酸成硫酸、S+Na₂SO₃ 煮沸制硫代
硫酸钠均需加热），H₂O₂ 例外（浓 H₂O₂ 室温即可氧化硫粉）。逆向
（S 被还原，如 Hg+S 室温研磨化合）不受限。

### 3.4 驱动力 S（S_of）

`S = logK(T) − logQ`。活度约定：溶质 ≈ 浓度（mol/L）；固相、溶剂 = 1；
气体见 §3.6。logK(T) 优先 van't Hoff（候选带 ΔH 时），否则 Nernst
k(T) 缩放（ΔS≈0 近似）。

### 3.5 平衡求解（solve_extent）

二分求 x* ∈ [0, x_max] 使 S(x*) = 0；x_max 由限量试剂决定。
`f(x)` 内做账本试推进后重估 S：

- **pH 跳过优化**：非 redox 且反应式两侧都不含 H⁺ 时，S 与 pH 无关
  （estimate_pH 不改账本），二分全程跳过缓冲滴定——这是求解器内最大的
  单项开销。redox 即使无 H⁺ 也必须走 estimate_state，因为其副产物账本
  要做强酸形态重排（NO₃⁻/HNO₃ 等），影响 S。

### 3.6 气液两相模型（第 300 轮重写：与固相严格同构）

外界气相：恒压（`p_kpa`，默认 101.3 kPa）惰性环境。气体有**恒压气相库**
`gas_phase`，进出双向可逆（等压膨胀），与"固相 ⇄ 溶解态"完全对称：

| | 固相 | 气相 |
|---|---|---|
| 相界常数 | `Ksp` | `c_sat = H(T)·p_ext`（泡点） |
| 有第二相 ⟹ 液相钉在 | Ksp 饱和浓度 | 泡点浓度 |
| 存量容器 | `ledger[X(s)]` | `gas_phase`（恒压气相库，mol） |
| 进出 | dissolve / precip | 鼓泡 / 回溶 |

- `H(T)` 由 298 K 亨利常数经 van't Hoff 修正（`henry_dH` 表，
  `henry_of(T, gas, T_K)`）；无 Henry 数据的气体用 `A_GAS` 作等效饱和浓度；
- **相转移由 `_equil_gas_phase` 做**：溶解量 > `cap` ⟹ 超额鼓泡进入气相库；
  溶解量 < `cap` 且气相库非空 ⟹ 回溶补充。**逸出不再销毁物质**
  （旧 `escaped` 是永久删除，已废除）；
- **`S_of` 无气体专属分支**：气体与所有溶质一样按真实溶解浓度计。
  泡点是**相界**（由气相库承载），不是活度修正 ⟹ 互逆反应
  `S_f + S_r = 0` 天然成立；
- **泡点只约束自产气体**：投料量用 `cap_eff = max(c_sat·V, 投料量)`
  ——投料气体是真实投进体系的量，不预先锁进气相（把投料也锁进去会让
  依赖溶解态驱动的反应全线崩：实测 −73）。
- `gas_escape=False` = 闭口体系：不建气相库，自产气体全部留在溶液。

呈现层 `final` / `production` / `consumption` 一律**总量口径 = 溶解态 + 气相**
（用户关心的是摩尔数总量）；`gas` 单列气相存量。

### 3.7 主循环（judge）

```
规范化 → [不动点迭代 → 气液两相平衡]× 至无新相转移：
  每轮：强酸形态重排 → pH 估计 → （必要时虚拟全形态分布落实）
       → 枚举候选 → 过滤（disabled/slow/膜封锁）→ 算 S → 取最大
       → solve_extent 执行 → 记录 step
收敛 → 输出 changed/reacted/degree/consumption/production/final/gas/steps/annotations/ionize
```

- `slow` 候选（恒慢/方向慢）不执行，可达显著程度时标注
  `annotations: ["slow"]`；`deferred` 候选在快候选耗尽后执行（见 §3.3
  的三层语义表）；
- **平衡冻结**（`frozen_perm`，v0.3.8 起四检测器）：① 极限环签名复现
  ② 近窗正反向对消（同键）③ 短周期重复 ④ **物种级周转冻结**——近窗
  （40 步）物种总周转（逐步 L1 累计）≥0.05 而账本净移 ≤2% 的多平衡乒乓
  （不同净键互为往返、extent 层净/毛恒 1 但物种原地踏步；Ag32 配位-氧化
  银 876 次乒乓即此类，1786→101 步）。冻结是对"步进分辨率已达平衡点"
  的处置，也是联立解 boundary 态（不动点在物理域外）的正确仲裁；
- **联立求解加速**（v0.3.8）：爬行检测（it≥64 且近 24 步全微步且 ≥2
  循环键）触发 joint.py——只联立解 hist 循环键匹配的平衡（Gauss-Seidel
  循环坐标的 Newton 加速；全收会因候选集跨数据源 Hess 互斥无解），
  成功跳步后 disabled.clear() 由 walk 全量重评估自校验；失败黑名单；
  idle 退出前精修（触发点②）已实现并按全量差分否决回退：Co32/Co33/
  T34/Fe33 四例——idle 点走步仲裁已完成，活动子集的联立不动点 ≠
  仲裁点，跳步=语义翻案；
- 钝化膜（`blocked_extent`）可永久冻结某方向（如 Al 在浓硝酸中）；
- 签名不变计数防空转（disabled 集合不变 ⇒ 收敛）。

### 3.8 OVERRIDE（逃生舱）

少数原理覆盖不到的反应（如某些络合溶解的特异配比）在 `overrides.json`
显式注册，命中时直接给出产物，跳过平衡求解，结果标注 `override` 字段。
这是逃生舱而非常规通道——能通过数据表推出的行为不允许走 OVERRIDE。


**性能结构（v0.3.6 稳态路径三件套，全部经 1205 例全量差分 sha256 比对
bit 级一致）**：

- **微步二分早停**（solve_extent `micro_rel` 快通道）：多平衡体系 walk
  中六成以上 pick 求解为微步（根 < 1e-4·x_max，结果只进 disable/idle
  废弃分支）——二分区间上界坍缩到微步阈值即止损，探针 ~47→~14；三重
  守卫（kind 非 dissolve/precip、nk 不在近 12 步 hist 键中、
  1e-4·x_max < BLOCKED_EXTENT）保证与跑满迭代在分支决策上等价；
- **微步排空（drain）**：pick 被判微步禁用后，若账本冻结（无强酸分子
  影子 → respeciate 结构性空转；realize/枚举/pH 均为账本纯函数），本
  轮评估结果 evals 仍完全有效——剔除已禁用者直接重挑次优，免去每个
  空转迭代一整轮 pH/形态/枚举/评估重算（FeCl₃+SCN 类体系空转可达
  数百迭代）；
- **枚举静态段 present 二级缓存**（templates `_enum_static2`）：静态
  （质子/沉淀溶解/氧化物酸溶/配位）+ Hess 派生候选的过滤只依赖 present
  物种集，与 pH/浓度闸门桶无关——浓度演化使层0 memo（含 conc 桶）反复
  miss 时此段仍命中（数千次 frozenset 子集扫描降为查表）。

引擎对象（system.Engine）把三层 API 收敛为平级方法：react() 直落
_solve()（不建 System）、System._react() 直落 _solve()（不经 react），
judge/react/system 三者零中间包装；模块级 react/System 为函数式便捷
入口（同语义、隐式全局表）。

## 6. 温度模块（thermo.py）

设计纪律：**只消费 judge() 的结果**——事后分析（analyze）与耦合求解
（coupled）都不在平衡求解路径上加任何判断语句；调用点只有
system.Reaction 包装层（isothermal=False 时）。thermo 延迟 import
engine（无环）。

**事后分析（analyze）**：净变换 net = production − consumption（气相
存量留在 net——它们是携带 ΔHf(g) 的产物；production 已是总量口径；
v0.3.3.0 曾减去 escaped，产气体系既丢焓又使 H/O 原子平衡必不闭合）+ H_excess 初/终
账户差 + 规范化中和步的 H⁺/OH⁻（v0.3.3.0 遗漏 → 纯中和体系净变换恒空、
报零热）。水量由 H/O 原子平衡双路重构校验（不一致即拒绝，宁缺毋假）。
ΔH = Σ net·ΔHf° + Δn(H₂O)·ΔHf°(H₂O,l)；ΔT 按水比热容（V×1000 g）。

**绝热耦合（coupled，isothermal=False 的语义）**：外层温度不动点

```
    T_f = T₀ + q(T_f)/(m·c_p)      q 随 T 单调减弱（放热 van't Hoff）
```

锚定初温 T₀ 结算（**不是** T += dT 相对更新——那会收敛到 q=0 的错误
不动点，"把反应热耗干"而非"绝热升温"）。收缩映射，实测 2–4 轮收敛
（容差 0.25 K，上限 6 轮）；相变平台钳制在 273.15/373.15 K（潜热不
建模，boils/freezes 标志如实报告）。|ΔT| < 0.25 K 或 ΔHf 数据不足时
单遍直出（与恒温耗时相同）。trace 逐轮记录 T/heat/dT 供检验。

热层已知边界（诚实记录）：固体投料溶解热不计（按"已溶解溶料"语义）；
SO₃ 类规范化阶段转变的投料 H/O 不闭合（heat=None；CaO 等氧化物投料拆解
出的晶格 O²⁻ 记账物种同理拒算）；ΔCp≈0（Kirchhoff）；逸出气体按同温
离开。

**ΔHf 单一事实源（v0.3.5）**：thermo.py 曾自带一份硬编码 DHF 副本，与
data/thermo.json 双源冲突（CO₂ 气相/水溶两套值混用）——已删除，统一走
`data.dhf_of`：thermo.json 裸名 = 引擎账本态（水溶/凝聚），"X(g)" 后缀
键 = 气相态（CO₂/SO₂/H₂S/NH₃）。热分析对净变换按账本态计价，
气相部分（结果键 `gas`）再按气相键校正（溶解→气相焓差如实入账：CaCO₃+HCl
的残留溶解 CO₂ 不再多计 20 kJ/mol 溶解热）。
