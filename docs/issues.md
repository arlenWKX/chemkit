## 2. 缺的数据

> 逐族条数用 `python tools/db_matrix.py` 现算；下表是家族级清单。

### 2.1 水解 / 羟合梯

| 缺什么 | 影响 |
|---|---|
| **ν=2,3 羟合条目**：Ga³⁺ / In³⁺ / Zn²⁺ / Cd²⁺ / Cr³⁺ / Be²⁺ | 这些中心只能走 `ν=1` 或 Ksp 派生复合近似 ⟹ 两性区与多核前区不准 |
| **Al³⁺ 的 ν=3** | 铝的水解分配（与 P1-6 相关） |
| **多核常数**（Al₁₃ 等） | 整族缺；酸性铝体系的主要物种缺位 |

### 2.2 温度依赖（`dH`）

| 表 | 覆盖 |
|---|---|
| `beta.json` | **9 / 194** |
| `pka.json` | 53 / 89 |
| `ksp.json` | 91 / 230 |
| `couples.json` | 100 / 180（含派生） |

缺 `dH` ⟹ 不做 van't Hoff（**宁缺毋假**），温度外推面窄。用例侧也只有 52 例设了 `T_K`。

### 2.3 固相

* **缺 `thermo`（无 `dH`）**：Cr(OH)₃、SiO₂、Ga(OH)₃、镧系 M(OH)₃ 成片缺失。
* **缺溶解度数据**：MnO₂、Fe₂O₃、PbO₂、MnOOH 等 6 条化合物固相。
* **相态声明不全**：`phase` 只覆盖 15 条。

### 2.4 氯合

* `[SnCl₆]²⁻`（`D05`）：无在案出处。
* `[AlCl]²⁺`：SIT 家族无此物种（只有 ε 行）——去留待定。
* `ε(Cr³⁺,Cl⁻)`：库内自标**「估计值」**（0.32 vs `sit.dat` 0.300）。
* **未核条目**：Be / Sc / Y / 镧系 / Hf / Zr 的 Cl⁻ 络合（都未与权威库对拍）。
* `[FeCl]²⁺`/`[FeCl₂]⁺` 等 Fe(III) 氯合：库内以 NEA-TDB I→0 值入库，但与实测 pH 窗
  （1 M FeCl₃）至今不能同时成立（历史遗留，见 `docs/limitations.md`）。
